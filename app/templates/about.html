Hackathon Overview

Dayflow — Human Resource Management System

Centralized employee identity, attendance, leave, and payroll workflows in one HRMS application.

What it does

Dayflow centralizes employee identity, attendance, leave, and payroll workflows in a single web application built for fast operational visibility. It features admin-provisioned authentication, a searchable employee directory with role-aware profile access, check in/out attendance tracking, structured leave request approvals, and an analytics dashboard with Chart.js visualization.

Core Differentiator

The payroll preview dynamically calculates payable days from real attendance records, public holidays, approved leave, and missing attendance. It prorates payroll and displays transparent component breakdowns including basic pay, allowances, employee and employer Provident Fund (PF), and professional tax.

Tech Stack

Built with FastAPI, SQLAlchemy 2.0, Alembic, PostgreSQL (production), SQLite (local development), JWT, Pydantic v2, Jinja2, Chart.js, and pytest.
